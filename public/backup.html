Backup & Restore

Create Backup

Click the button below to download a complete backup of the current database. This file contains all contests, candidates, scores, and users. Store it in a safe place.

Restore from Backup (.zip or .db accepted)

Select your downloaded .zip backup file to restore both the database and all candidate/contest photos, or select an extracted tabulation.db file to restore only the database.

WARNING: This is a destructive action!

Restoring will completely erase and overwrite the current database (and photos when restoring from a .zip backup). Any changes made since the backup was created will be lost. This action cannot be undone.
